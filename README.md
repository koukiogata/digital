# 数字で分かる求人情報サイト - デジタル書籍サンプル

## 概要
このプロジェクトは、**デジタル書籍**形式で提供する求人情報サイトのサンプルとして制作されました。求人情報を統計データやグラフで視覚化し、ユーザーが求人の特徴や傾向を「数字で理解」できるように設計されています。業界ごとの平均給与や労働時間など、求職者が重視するデータを分かりやすく提供することを目的としています。

## 主な機能
- **求人情報のデータビジュアライゼーション**  
  統計情報やグラフを活用し、求人情報を視覚的に表示します。

- **業界ごとの詳細データ**  
  業界別に給与、年収、残業時間、休日数などのデータをまとめて提供し、求人比較が容易になります。

- **インタラクティブなグラフ表示**  
  ユーザーがデータをフィルターやソートできるグラフを実装し、求職者が自分に合った情報を見つけやすいよう配慮しています。

## 使用技術
- **フロントエンド**: HTML, CSS (SCSS), JavaScript
